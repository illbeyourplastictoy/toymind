# 🃏 Pokemon News Agent

AI-агент, который **раз в 6 часов** мониторит новости рынка коллекционных карт
покемонов (Pokemon TCG), присылает тебе в Telegram **сводку + готовый черновик
поста в твоём стиле**, и после твоего **апрува кнопкой** сам публикует пост
(с картинкой) в твой канал.

## Как это работает

```
RSS-ленты  ──►  Claude (сводка + пост в твоём стиле)  ──►  картинка
                                                              │
      ты в личке бота: ✅ Опубликовать / 🔁 Перегенерировать / ✖️ Пропустить
                                                              │
                                             ✅  ──►  пост в твой канал
```

- **Сбор новостей** — `news.py`, RSS через `feedparser`. Источники в `feeds.txt`.
- **Сводка и пост** — `content.py`, Claude API (`claude-opus-5` по умолчанию),
  стиль берётся из `style.md`.
- **Картинка** — `images.py`: генерация через подключаемый image-API
  (OpenAI-совместимый), иначе картинка из статьи, иначе — без картинки.
- **Аппрув и публикация** — `bot.py`, `python-telegram-bot` (кнопки + планировщик).
- **Антидубли** — `state.py`, JSON-файл `state.json`.

## Установка

```bash
cd pokemon_news_agent
pip install -r requirements.txt
```

## Настройка

### 1. Переменные окружения

| Переменная          | Обязательна | Что это |
|---------------------|:-----------:|---------|
| `TG_BOT_TOKEN`      | ✅ | Токен бота от [@BotFather](https://t.me/BotFather) |
| `TG_OWNER_CHAT_ID`  | ✅ | Твой личный chat_id (куда слать черновики) |
| `TG_CHANNEL_ID`     | ✅ | Канал для публикации: `@username` или числовой id |
| `ANTHROPIC_API_KEY` | ✅ | Ключ Claude API |
| `POKENEWS_MODEL`    | — | Модель (по умолчанию `claude-opus-5`) |
| `CHECK_INTERVAL_HOURS` | — | Интервал проверки, по умолчанию `6` |
| `IMAGE_API_URL`     | — | Эндпоинт генерации картинок (OpenAI-совместимый) |
| `IMAGE_API_KEY`     | — | Ключ для image-API |
| `IMAGE_MODEL`       | — | Модель картинок (по умолчанию `gpt-image-1`) |

**Как узнать `TG_OWNER_CHAT_ID`:** запусти бота, напиши ему `/start` — он ответит
твоим chat_id.

**Важно:** добавь бота в свой канал **администратором** с правом публикации.

### 2. Стиль постов

Отредактируй `style.md` — опиши тон и **вставь 2–3 своих реальных поста**.
Чем конкретнее, тем ближе результат к твоему голосу.

### 3. Источники новостей

Правь `feeds.txt` — по одной RSS-ссылке на строку. Уже добавлены PokeBeach и
несколько запросов Google News по рынку TCG (в т.ч. на русском).

## Запуск

```bash
cd pokemon_news_agent
python run.py
```

Бот начнёт проверять новости каждые `CHECK_INTERVAL_HOURS` часов.
Команда `/check` в личке — проверить прямо сейчас.

## Заметки

- Картинки: без `IMAGE_API_URL` агент берёт картинку из статьи (если есть) или
  постит текстом. Любой OpenAI-совместимый `images/generations` подойдёт.
- Черновики хранятся в памяти процесса. Если бот перезапустится с висящим
  черновиком — просто дождись следующей проверки или вызови `/check`.
- Развёртывание: держи процесс живым (systemd / Docker / любой хостинг),
  переменные окружения — через секреты. `state.json` желательно на постоянном диске.
- Это отдельный модуль и не связан с крипто-ботом ToyMind в корне репозитория.
